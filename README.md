# 🤖 113 Winter Vacation — AI & Data Science Practice

本專案為寒假自主學習與實作紀錄，主要以 **Python、人工智慧、資料分析與生成式 AI** 為核心，透過不同主題的實作，學習如何將 AI 技術應用於實際問題。

專案內容涵蓋 **網路爬蟲、YOLO 物件偵測、Power BI 數據視覺化、GPT-3.5 API、生成式 AI，以及 2D 圖像轉 3D 模型** 等主題。

---

## 📌 Project Overview

本專案將不同 AI 與資料處理技術分成多個實作主題：

| 主題            | 技術                  | 說明                 |
| ------------- | ------------------- | ------------------ |
| 🕷️ 網路爬蟲      | Python              | 網頁資料擷取與資料整理        |
| 👁️ YOLO 物件偵測 | YOLO / Python       | 使用電腦視覺進行物件偵測       |
| 📊 Power BI   | Power BI            | 資料分析與互動式視覺化        |
| 💬 GPT-3.5    | OpenAI API / Python | 串接大型語言模型 API       |
| 🎨 生成式 AI     | Generative AI       | 探索 AI 生成內容的應用      |
| 🧊 2D → 3D    | Generative AI       | 嘗試將 2D 圖像轉換為 3D 模型 |
